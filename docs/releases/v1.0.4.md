# Auriqo v1.0.4

Release date: 2026-08-20

This is the first production-signed stable release. Playback was restored after the upstream Echo
Music repository (the previous source of the YouTube player-hash table) was retired; the runtime
cipher-config sync now reads from the `ZemerTeam/zemer-cipher` upstream and covers the current
player hash `3891b194` (STS 20681). The app also now shows play counts and like counts for songs
across search, artists, albums, playlists and the player screen.

Phone and Wear declare `versionCode 3` and `versionName 1.0.4`.

Install the matching FOSS or GMS phone APK and, on Wear OS watches, the Wear APK. Because this is
the first release signed with the protected production key, devices with a previous debug-signed
alpha installed must uninstall once before installing this build. After that transition, updates
install in place.

# Auriqo v1.0.3-alpha

Release date: 2026-08-15

This is an alpha/test release, not an official stable build. All three APKs are signed with the
repository's public persistent debug identity. Android therefore reports `versionCode 1` and
`versionName 1.0.0` inside the packages even though the source release is tagged
`v1.0.3-alpha`. Do not use these artifacts as a production signing baseline.

> For phone-to-Wear connectivity, use the corrective [`v1.0.3-alpha.1`](v1.0.3-alpha.1.md)
> release. The Wear artifact listed below predates the package-name fix and is superseded.

## Highlights

- Replaced the reconstructed lyrics animation with a faithful Android adaptation of the renderer
  pinned to Better Lyrics commit `931f25829f6cfd81d0042ca36b4308a0cd38d467` and
  `@braccato/core@1.1.0`.
- Added in-screen source switching, stable per-candidate offsets, translation/romanization,
  app-private custom lyrics fonts, appearance controls, same-activity PiP and crash recovery.
- Added a verified Better Lyrics theme marketplace, declarative bounded shader runtime and signed
  Unison nickname/vote/report/submission actions.
- Updated Media3 to 1.10.1 and rebuilt the Wear OS companion and Tile with rich playback state,
  progress, like, shuffle and repeat controls.
- Completed the Auriqo visual pass with fixed Cabinet-derived vector artwork while removing the
  Cabinet font software and obsolete raster branding from the APK.

## Verification performed

- Better Lyrics web tests and reproducible asset build: 9 tests passed.
- Unison, Better Lyrics, Wear, Letras.com and app unit tests passed.
- `lintUniversalFossDebug` passed with 421 tasks.
- FOSS, GMS and Wear debug assemblies completed successfully.
- The Wear APK was installed and launched on a Galaxy Watch `SM-R965U`; final visual inspection
  behind the watch keyguard was not possible without the user's pattern.
- APK contents were checked for the generated Better Lyrics assets, Auriqo phone/Wear vectors,
  absence of Cabinet font binaries and absence of obsolete Echo-named drawable resources.

## Licensing and boundaries

Better Lyrics is GPLv3; the exact adapted renderer boundary and hashes are documented in
[BETTER_LYRICS_SNAPSHOT.md](../BETTER_LYRICS_SNAPSHOT.md). `@braccato/core` and
`@braccato/types` declare MIT. Auriqo packages fixed Cabinet-derived logo outlines, not Cabinet
font software. See [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md) and
[PROVENANCE.md](../PROVENANCE.md).

Rich custom Wear synchronization requires the GMS phone APK. The FOSS APK still publishes standard
Media3 controls to compatible system surfaces. Theme, lyrics-provider and Unison availability can
change independently because they are remote services.

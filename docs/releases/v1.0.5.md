# Auriqo v1.0.5

Release date: 2026-08-21

This stable release completes the playback migration to native Rhino execution for YouTube cipher
and n-transform code. WebView is used only for PoToken acquisition. NewPipe Extractor is updated to
`0.26.2`, and extractor/cache state is serialized across restarts.

The player and media details now share a compact, accessible presentation for views and likes. YouTube
song lists and grids also show view counts consistently when the provider places them in different
metadata columns.

Phone and Wear declare `versionCode 4` and `versionName 1.0.5`.

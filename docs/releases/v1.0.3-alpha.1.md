# Auriqo v1.0.3-alpha.1

Release date: 2026-08-15

This patch release fixes phone-to-Wear discovery. Google Play Services Data Layer requires the
same application package and signing certificate on both devices. The Wear APK now declares
`com.auriqo.music`, matching the phone APK; its Kotlin namespace remains `com.auriqo.music.wear`.

Install the matching GMS phone APK and this Wear APK. If the old Wear package
`com.auriqo.music.wear` is still installed, remove that obsolete companion first.

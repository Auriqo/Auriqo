# Roadmap

This roadmap describes areas the maintainers would like to improve. It is a guide, not a promise of dates or a guarantee that every item will ship.

## Near-term priorities

- Keep the FOSS reference build easy to compile and install.
- Reconcile release version metadata before the next official release.
- Improve test coverage around playback, lyrics parsing, playlists and account flows.
- Keep provider integrations resilient when upstream APIs change.
- Finish the remaining dependency and asset provenance review for official artifacts.

## Product direction

- Make playback, queue and library flows feel dependable across phones, tablets and supported Wear OS surfaces.
- Improve lyrics discovery, synchronization and fallback behavior.
- Make optional integrations such as scrobbling, Discord Rich Presence and Listen Together easier to configure and troubleshoot.
- Keep FOSS and GMS variants clearly explained and independently buildable where possible.

## Collaboration

Good roadmap contributions include focused bug fixes, provider adapters, tests, accessibility improvements, translations, documentation and current screenshots. A proposal is most useful when it explains the user problem, the expected behavior and how it fits existing compatibility constraints.
